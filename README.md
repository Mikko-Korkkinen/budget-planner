# budget-planner

# Features:

* User is able to create and log into an account.
* User is able to create, edit and delete budget plans.
* User is able to share budget plans to other users.
* User has their own private page on the web-app where they can see their own plans and plans that are shared by other users, as well as their statistics such as the amount of accessable plans.
* User is able to name their plans as well as add a budget and expenses to the plan.
* User is able to search for plans by their title.
* Budget plans are classified as one of the following: personal, household, business or other. User is able to choose the classification of the plan.
* If a plan is classified as "other", user is able to name the class themselves.
